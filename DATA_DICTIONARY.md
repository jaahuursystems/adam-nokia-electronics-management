# Data dictionary
Source of truth: the `SCHEMA` array in `apps-script/Store.gs` (sheet tab → columns, with type codes s=text, n=number, b=boolean, j=JSON). Money is stored as integer minor units (USD cents, SLSH whole, AED fils); each money record carries its exchange-rate snapshot. Tabs include Settings, Meta, Roles, Staff, Sessions, PaymentMethods, ExchangeRates, Products, Inventory, StockMovements, Customers, Sales, SaleItems, Payments and the branch, purchasing, expense and reconciliation tabs. A generated full dictionary will replace this stub once the schema changes in Phase 4 are finished.
